## 基本情報

- ゲーム名: あにあにの遊び場
- 英語表記: ANIANI PLAYGROUND PORTAL
- 種別: ゲーム作品ポータル兼ミニゲーム集
- ゲームジャンル: ポータルUI、カジュアルミニゲーム集
- エンジン: Unity不使用。ブラウザ標準技術で実装。
- 目的: あにあに制作作品を宇宙に浮かぶゲームソフトとして見つけ、詳細確認、外部ゲーム起動、ミニゲーム、更新情報、コメント、コレクション機能を一か所から利用できるようにする。

## ポータルの基本仕様

### 実装済み

- 1画面固定の宇宙ポータルに、ゲームソフト型カード5件が円軌道で回転する。
- 初期選択は `Battle a la carte`。前後ボタン、左右キー、スワイプで作品を選択し、作品カードまたは「作品をひらく」で詳細モーダルを開く。
- 周回は停止・再開できる。ホバー中、フォーカス中、モーダル表示中、ページ非表示中は自動周回しない。
- `prefers-reduced-motion` が有効な環境では初期状態で周回を停止する。
- すべての主要情報はモーダルで表示し、背景クリック、×、Escapeで閉じる。
- 作品詳細モーダル（`#battle-detail` / `#battle-3d-detail` / `#tumikomi` / `#oshi-detail` / `#bunko-detail`）は、URL末尾のハッシュで直接開ける。詳細を開くとアドレスバーのURLがそのハッシュに変わり（履歴は増やさない）、閉じるとハッシュを外す。その他のモーダルは対象外。
- SNS共有用にOGP / Xカード（`images/ogp-20261008.jpg`、1200×630）とファビコン（`images/favicon.svg`、`images/apple-touch-icon.png`）を設定する。
- トップの常設フッター、ゲーム一覧、各作品詳細、ミニゲーム一覧に、画像・文章・ゲームデータの無断転載・無断配布を禁止する注意書きを表示する。

## ミニゲーム

共通進行:

1. 「ミニゲーム」モーダルを開く。
2. 右側タブからゲームを選ぶ。
3. 全画面APIが使える場合は全画面へ入り、使えない場合は画面内の固定レイアウトで開始する。
4. 右上の×でゲーム一覧へ戻る。`← ホームへ戻る` でポータルへ戻る。

### 〇×ゲーム

- 9×9盤面、○と×の2人交互操作。
- 縦・横・斜めのいずれかに先に5個並べた側が勝利。
- 盤面が埋まって5個並ばなければ引き分け。
- CPU対戦はない。

### 神経衰弱

- 材料カード15種類を2枚ずつ使用する30枚構成。
- ニックネーム入力後に開始し、全15ペア成立までの時間を計測する。
- ランキングは所要時間の短い順で端末内に保存する。
- スマホではScreen Orientation APIが利用可能なら横向きを要求する。利用不可時はCSS回転レイアウトへフォールバックする。

### もぐらたたき

- 3×3の9穴、制限時間20秒。
- もぐらは出現対象の75%。うさぎ・犬は残り25%から選ばれる。
- もぐらを叩くと+1点、うさぎまたは犬を叩くと-2点。
- 時間終了時のスコアを表示する。ランキング保存はない。

### 反射神経テスト（カウボーイ決闘）

- スタート後、1.4秒から4.0秒未満のランダム待機後に「！」を表示する。
- 「！」表示後にカウボーイ画像をタップ・クリックして反応時間をミリ秒表示する。
- 合図より前の操作は早撃ち失敗。
- ベストタイムは端末内に保存する。

### ブロック崩し

- Canvas 360×300、7列×4行の料理画像ブロック、残機3。
- パドルでボールを返し、全28ブロックを破壊するとクリア。
- ブロック1個につき10点。ボールを落とすと残機が1減り、0でゲームオーバー。
- マウス・タッチ位置または左右入力でパドルを動かす。

### スネークゲーム

- 15×15盤面。125ms間隔で進む。
- エサを食べると体が伸び、10点加算される。
- 壁または自分の体に衝突するとゲームオーバー。

### 簡単テトリス

- 10列×18行、7種類のテトロミノを使用。落下間隔450ms。
- 左右移動、下移動、時計回り回転に対応。回転時は左右最大2マスの補正を試す。
- 次のピースと2番目のピースを上下に表示する。
- ライン消去得点は、1回の消去ライン数の二乗×100点。
- 新しいピースを配置できなければゲームオーバー。
- ホールド、ハードドロップ、レベルアップ、7-bag方式は実装されていない。

### 8パズル

- 3×3盤面で1〜8を左上から順番に並べ、右下を空きマスにするとクリア。
- 完成形から合法手を24回行って、必ず解ける初期配置を生成する。
- タップ、方向入力に対応。やり直しは同じ初期配置へ戻す。
- 手数を表示する。ランキング保存はない。

## 操作方法

### ポータル

- マウス・タッチ: ボタン、カード、スワイプ。
- キーボード: 左右キーで軌道作品選択。通常フォーカス外ではEnterで選択作品を開く。Escapeでモーダルを閉じる。

### ミニゲーム共通方向入力

- `W` / 上矢印: 上。テトリスでは回転。
- `D` / 右矢印: 右。
- `S` / 下矢印: 下。
- `A` / 左矢印: 左。
- 左下に仮想十字キー、テトリスは右下に回転・1段下降ボタンを用意する。キーボードの上/W回転は維持し、タッチパッドの上回転は非表示。
- ブロック崩しのタッチパッドは左右のみ。他の対象ゲームは上下左右。斜め入力は現行ルールにないため追加しない。
- 開始・リセット操作は盤面外の共通操作デッキへ配置。既存ボタンとイベント処理を維持し、押下域は44px以上。
- 縦向きでは下部に操作デッキを確保し、横向き/PCでは盤面左右に操作域を分ける。Safe Areaと動的ビューポート高に対応する。
- 方向入力が使われる対象はスネーク、ブロック崩し、簡単テトリス、8パズル。各ゲーム固有ボタンも存在する。

## セーブ仕様

### ブラウザ端末内

- `localStorage` に記事コメント、来訪者コメント、神経衰弱ランキング、反射神経ベストを保存する。
- 無料試験ガチャの所持枚数を `aniani.trial-gacha.v1.inventory` に保存する。これは共通アカウントの所持カードとは別データ。
- 保存内容は端末・ブラウザごとであり、別端末や別ユーザーとは共有されない。
- ガチャ通信中のリクエストIDもユーザー単位で一時保存し、再送時の二重消費を防ぐ。

### Supabase

- 認証済みユーザーのプロフィール、コイン残高、台帳、カード所持、デイリー受取、ガチャ結果、実績受取をPostgreSQLへ保存する。
- RLSによりユーザーは自分のデータだけを読み取れる。残高・所持カードの直接書込みは許可しない。

## 通信仕様

- ポータル本体とミニゲームは、Supabase共通機能を除き静的・クライアント完結。
- 共通機能はHTTPSでSupabase REST/RPCへ接続する。公開可能キーとログイン後のJWTを利用する。
- API要求のタイムアウトは20秒。
- ガチャはクライアント生成UUIDを冪等キーとして使用し、不確実な応答時は同じUUIDで結果を再確認する。
- `@supabase/supabase-js@2.57.4` を `https://esm.sh/` から動的に読み込む。
- Google Fontsを外部配信で利用する。
- リアルタイム通信、WebSocket、対戦通信はポータル本体にない。

## プレイヤー・CPU・キャラクター

- ポータルと無料試験ガチャは匿名で利用できる。Supabase側の共通コイン、デイリー、コイン消費ガチャ、共通所持図鑑にはプレイヤーアカウントが必要。
- プレイヤー対戦は〇×ゲームの同一端末2人交互操作のみ。
- CPU対戦、NPC AI、難易度AIは実装されていない。
- 推し駒battleは、作品詳細に試験版2の対戦画面（`images/oshikoma/board-20261002.jpg`、推し駒battle紹介ページの実画面のコピー）とキャラクター画像4枚（猫ビショップ、犬ルーク、鹿ビショップ、銀狼）を掲載する。対戦画面は16:9の全体表示で、画像を押すと別タブで原寸表示。旧 `images/oshikoma-board.jpg` は保持。
- 推し駒battleの紹介には、試験版2の新UI・スコア/コンボ・階層ランク・BGMと、標準15秒の手番制限（なし/30秒/15秒/8秒の設定）を記載する。ゲーム内容の根拠は `../推し駒battle/Site/` と同作品の文書。ポータル自体でゲームを起動するものではない。

## カード・アイテム・報酬

### 無料試験ガチャ（公開用実装）

- ログイン、あにあにコイン、現金を使用せず、10連を何度でも試せる。結果と重複枚数はブラウザ端末内だけに保存する。
- コレクション全159種。Battle a la carte 51種、架空運輸41種、小説3作品43種（星20、花8、EchoShion15）、推し駒battle 24種。未入手番号を押すと入手条件を表示する。入手済みカードは1回のクリック・タップ、Enter・Spaceで画像を拡大する。
- Battle a la carteは素材15種=C、料理12種=SR、イベント9種=SSR、キャラクター8種=UR、着せ替え7種=SSR。キャラクターURは暁、千鶴、舞依、拓海、剛、栞那、結月、龍太のBattle Modeカットイン画像を使用する。着せ替えは暁・剛のサマービーチ、千鶴のブラックキャット、栞那のウィッチ、舞依・拓海・結月の弓道着。名前・衣装・画像は公開ゲームのデータに合わせる。
- 推し駒battleは公式サイト「推し駒図鑑」の24人。UR＝最初から選べる蓮・結衣・美桜・歩太と黒獅子王、SSR＝黒金会の幹部（豹妬レイラ・銀狼シオン・鹿角ノア）、SR＝救出で解放される16人。名前・役割・固有スキル名・紹介文は公式サイトの表記を使い、URの演出では紹介文を「キャラクター紹介」として表示する（台詞を新しく作らない）。生成AIを使用したイラストであることを明記する。
- 架空運輸は車両5種、既存ホームページ由来の社員6枠、新規架空社員30名。車両種別と社員の役職に応じてC/SR/SSR/URを設定する。
- 小説の主要キャラは、星の終わりに君は生きる: 透真・湊=UR、ハル・シロ・紗良=SSR。花散るさきの、幸せのかたち: 咲・花=UR、エドワード=SSR。EchoShion: 志遠・澪・EchoShion=UR。ECHO-Usaとスーパーで棚に商品を並べる人型ECHOは各1枚=C。シロの低レア版は作らない。
- 家族・脇役30枚はC 17枚 / SR 13枚で追加。名前のない家族には固有名を付けない。小説画像43枚は生成AIを使用したことをガチャ・人物紹介・画像拡大で明記する。
- 公開済み124枚のID・番号・レアリティ・紹介文・所持データの保存キーを維持する。依頼された画像差し替えは咲の質素な室内版、志遠の姉の重複した右腕修正、父2人の外見調整、架空運輸の車両5枚。澪の父は眼鏡を追加し、志遠の父は大型バイクにまたがるサングラス姿の強面にして区別する。車両の緑色と白いラインを維持し、実車の構造と異なる角度で描く。トレーラーはトラクターと荷台の分離・連結部分を見せる。車両にも生成AI使用を明記する。5作品の図鑑フィルターと、小説サイトの人物紹介への作品別リンクを用意する。
- カード枠は全種類共通の2:3とし、図鑑・結果一覧・1枚ずつの演出で画像全体を表示する。下部の拡大ボタンも演出枠内に収める。枠はレアリティ別にC＝鋼、SR＝銀、SSR＝金（四隅の宝石つき）、UR＝回転する虹色の枠と上部の星の紋章とする。キラは常時表示し、SRは光沢、SSRは金のきらめき、URは虹のホロとグリッターを重ねる。マウス・指の位置に合わせてカードが傾き、光が動く。演出・結果一覧・図鑑・拡大表示に共通で適用する。動き低減設定ではアニメーションと傾きを止める。
- 排出率はC 60%、SR 25%、SSR 10%、UR 5%。確定枠・天井なし。
- 10連開始時は、真上から見下ろした底の見えない夜の海（水平線なし、水面に星空が映る）へ、CSS 3Dの立体コイン（厚みのある縁・金属光沢・刻印）を10枚同時に投げ入れる。10個の波紋が重なって水面の星が揺らぎ・ぼやけ、画面が一瞬で上へ持ち上がって全面の夜空（天の川）を映す。流れ星が斜めに落ち、画面が追って下がり、流れ星が海へ落ちた閃光からデジタル空間へ移る。海面・夜空・流れ星はCanvasで描き、波紋は高さ場のシミュレーションで表す。カードはデジタル空間で、光の線から走査線・格子を経て実体化し、背景のデータの文字は画面の下端まで流れ切る。「次のカードへ」と「演出をスキップ」を用意する。画面上の文言は「無料お試しコイン」とし、あにあにコイン（共通コイン）は消費しない。
- 10連の結果にURが1枚以上含まれる時だけ、波紋の後に海の底から光が湧き上がり、水面が下から明るく光る確定演出（光の柱、浮かび上がる光の粒、衝撃波）を表示する。排出率・確定枠・天井には影響しない。
- URの直前だけ「UR SIGNAL」の虹色のデジタル信号演出を表示し、台詞を挟んでから虹の放射光とともにカードを公開する。Battleの8人はストーリーモードの性格・口調に合わせたガチャ用台詞を「キャラクター台詞」として表示する。小説URは「登場人物紹介」と明記した紹介文を表示する。
- 最後の10枚の結果一覧は、PC・スマホの画面サイズと向きに合わせてスクロールなしで全10枚を表示する。演出枠と操作を片づけ、同じ2:3比率のカード、再抽選ボタン、保存結果を画面内に収める。結果カード全体をクリック・タップ・Enter・Spaceで拡大できる。

### 共通コインガチャ（ローカル版・Supabase実装）

- DB上のコレクションカード全16種。ガチャカード12種、実績カード4種。
- レアリティと確率はC 60%、SR 25%、SSR 10%、UR 5%。確定枠・天井なし。
- 1回100あにあにコイン。1回引きと10回引きに対応。重複カードは所持枚数を加算する。
- デイリーログイン報酬100コイン。ガチャを1回引いた日のデイリー報酬20コイン。
- 日付判定はサーバー側の日本時間で、各報酬は1日1回。
- ゲームクリア実績カード4種はDBへ登録済みだが、付与機能は無効。
- UIはローカル作業版にあり、公開用GitHub Pagesには未反映。認証済みE2Eは未確認。

## 管理・記事・コメント

- 更新記事は `aniani.js` の `officialArticles` で管理する公式記事。追加・修正はコード更新と公開で行い、全員に同じ内容が表示される。2026-09-29に簡易管理者モード（ブラウザ内投稿・削除とパスコード）を廃止。
- 公式記事には任意でスクリーンショット（代替テキスト・見出し・説明付き）と関連リンクを掲載できる。画像を押すと別タブで原寸表示。ギャラリーはPCで先頭を全幅/残りを3列、640px以下で1列とする。試験版2の記事には対戦・主人公選択・敵情報・祝福の4画面を掲載する。
- 記事コメントと来訪者コメントはブラウザ内のローカル機能で、他ユーザーと共有されない。
- ポータル上の作品導線は「スマホ版」ではなく「モバイル版」と表記する（リンク先URLは変更しない）。
- 公開版のマイページ（コイン・図鑑）は、共通アカウントの正式公開まで「準備中」表示。`common/portal.js` が読み込まれた場合だけアカウントUIを表示する。
- コメントはHTMLエスケープして表示する。
